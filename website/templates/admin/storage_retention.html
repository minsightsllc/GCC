What counts toward storage

Moving a file to Trash hides it from employee, client, and public views, but it remains in Static File Storage and continues using space until deletion succeeds. Trash has no automatic expiry.

The Static File Storage meter is project-wide and may include objects in other buckets. This inventory lists only uploads managed by GCC in its configured storage. Database Disk Storage is separate; Activity history and other records use it.

Restored files stay in Recovered until you reattach them. Reattaching to an already public record may make the file visible immediately, so review that record's sharing and publishing settings first. Signed agreements and cost receipts can only be removed when their archived project is permanently deleted.
